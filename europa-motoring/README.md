# Europa Motoring by NHM

The site is in `site/` and uses static HTML, CSS, JavaScript and SVG. It has no build step. Serve the repository root locally and open `/europa-motoring/site/index.html`, or point a future static host's asset directory at `europa-motoring/site/`.

This remains in the same repository as NHM and Woodward Avenue. The root NHM site is currently published with GitHub Pages. The existing `wrangler.jsonc` deploys only `woodward-avenue/site/`; it must **not** be changed to point at Europa. A separate Europa deployment needs its own Cloudflare project or Worker configuration and domain mapping after the intended host is confirmed.

The supplied Europa mockup sets the palette: Midnight `#101923`, Platinum `#B9B8B2`, Ivory `#F4F0E6`, NHM Red `#DC010F`. The SVG mark is a clean web interpretation of the emblem shown in the supplied composite mockup. The composite is not used directly because it also contains example identity and contact details that are not NHM's.

The site is informational. Model names are illustrative candidates, not inventory. No vehicle services are offered through it yet. Before an operational launch, verify the business entity, service terms, actual inventory, contact process and hosting/privacy disclosures.
